# ASHREKA ♡
### Handcrafted Chenille Floral Art & Bespoke Bouquets

**ASHREKA** crafts everlasting pipe-cleaner flower bouquets, signature ruffled lilies, cute floral keychains, and aesthetic customized gift hampers. Flowers that never wither, crafted with 100% love.

## ✨ Features
- **Signature Floral Collection**: Handcrafted ruffled lilies, chenille tulips, fluffy daisies, velvet sunflowers, forever roses, and lilac lavender.
- **Interactive Live Bouquet Builder**: Customize flower stems, select color aesthetics, wrap finishes, and fairy lights, then dispatch orders directly to WhatsApp or Instagram.
- **Customer Wishlist & Drawer**: Real-time pricing calculator and order summary.
- **Fully Responsive Design**: Optimized for mobile, tablet, and desktop screens.

## 🚀 Quick Start
Open `index.html` in any web browser, or serve locally:
```bash
# Using Python
python -m http.server 5500

# Using Node / npx
npx serve .
```
